# 衣服管理系统 - 微信小程序端

与 `backend/`（Flask）和 `frontend/`（Vue 网页）共用同一个后端与数据库，数据互通。

## 开发环境运行

1. 先启动后端（参见根目录 README），确保跑在 `http://127.0.0.1:18888`。
2. 用**微信开发者工具**导入本目录（`miniprogram/`）。
3. 工具右上角「详情 → 本地设置」勾选 **「不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书」**，即可直接请求本地后端。
4. 小程序内「我的 → 服务器地址」可随时修改后端地址（默认为线上服务器；本地调试时改成 `http://127.0.0.1:18888`，真机调试时改成电脑局域网 IP，如 `http://192.168.x.x:18888`）。

## 发布前必做

1. 后端部署到云服务器，配置 **已备案域名 + HTTPS**（如 `https://api.example.com`）。
2. 小程序后台（mp.weixin.qq.com）→ 开发管理 → 服务器域名，配置：
   - `request合法域名`：`https://api.example.com`
   - `uploadFile合法域名`：`https://api.example.com`（上传衣服图片）
   - `downloadFile合法域名`：`https://api.example.com` **以及腾讯云 COS 域名**
     （形如 `https://<bucket>.cos.<region>.myqcloud.com`，否则衣服图片无法显示）
3. 发布版本里在小程序内把服务器地址改为线上域名。

## 功能

- 登录 / 注册（验证码、管理员审核流程与网页端一致）
- **记住密码**：登录页勾选后，账号密码加密存于本地存储，下次自动填充
- 衣柜：搜索、季节/分类/位置多选筛选、多种排序、「好久没穿」筛选、双列固定高度网格 + 骨架屏、预览大图
- 穿着记录：卡片上一键「今天穿」（可撤销），显示穿过几次/上次穿的日期
- 搭配：2~8 件组一套、命名保存、一键记录今天穿了这套
- 添加/编辑衣服：拍照或相册选图上传（腾讯云 COS）、自定义分类/位置、季节多选
- 我的：数据统计、穿着日历、分类管理、位置管理、个人资料、服务器地址设置、退出登录
- 管理员：「我的 → 用户审核」可在手机上通过新用户的注册申请（其余管理功能请用网页端）
